# Changelog

All notable changes to Library flyer maker are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] – 2026-09-16

First public release.

### Added

- A4 flyers with QR codes for web addresses, e-mail addresses, phone numbers and text.
- Templates: resource guide, new-resource spotlight and blank.
- Layouts: two columns, wide rows and spotlight; six color themes, own colors, two typefaces, three card styles and three QR code sizes.
- Checks before printing: page overflow, QR code contrast (including light codes on dark backgrounds), text and link contrast, text that doesn't fit, example text and example links, internal addresses.
- Export to PDF with clickable links and a searchable text layer (Latin and Cyrillic), PNG export and printing.
- My flyers: several flyers are stored in the browser; new flyers keep the logo, colors and footer; duplicate and delete with undo.
- Project files (.json) to back up flyers and share them; older project files can still be opened.
- Undo and redo for every change, with keyboard shortcuts.
- Drag and drop of resources, also between sections; duplicate resources and sections.
- Interface in English, German and Russian with a language switcher; neutral example content in all three languages.
- Hyphenation based on the language of the flyer.
- Works fully offline; all libraries are bundled.
- Released under the GNU General Public License v3.0 or later.

### Security

- Project files and stored data are validated before use.
